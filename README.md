# 🛰️ ORBITRON — public vault

> **An open look at how one person, working with an AI agent under written rules,
> builds and documents a market-mechanics research project.**

This is an **[Obsidian](https://obsidian.md) vault**. Clone it, open the folder as a
vault, and the links, folders and callouts render the way they were written. It also
reads fine straight on GitHub — the folder names are the table of contents.

---

## ⚠️ Disclaimer — read this first

**ORBITRON is a personal research project. Nothing here is financial advice.**

- It does not sell signals, subscriptions, copy-trading or a course.
- It does not manage anyone else's money, and never will.
- No claim of profitability is made anywhere in this vault. The measure of success
  at this stage is **honesty, not return**.
- Any numbers you find are illustrations of method, not a track record.

If you came looking for a system that makes money, this is the wrong repository.
If you came looking for how a research system is *built* — welcome.

## 🔒 What is deliberately not here

Infrastructure details, network layout, hostnames, credentials, exact thresholds,
weights, and the pattern code itself. This vault shows **how the project thinks**,
not the numbers it trades on. That boundary is drawn on purpose and is not an
oversight.
